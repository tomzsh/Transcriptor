# Transcriptor

Android app for people turning local recordings into readable transcripts and subtitles. Main jobs: transcribe audio/video locally, read or edit the result, translate the existing text with a chosen AI model, and export the selected view.

Private Whisper transcription is available on Android 8+. AI translation offers explicit cloud BYOK or offline GGUF processing on the phone. Original text, cue timings and manual speaker names remain editable and retained. Model settings offer user-initiated in-app Qwen3.5/Gemma/Llama downloads, verified by size and SHA-256, plus explicit active selection and optional GGUF imports. Accuracy and language coverage depend on the chosen model.

The default project view prioritizes reading: continuous paragraphs without segment labels, timestamps or speakers. Users can reveal details and apply the same output settings to copying and document export. Timed subtitle formats remain standards compliant. Indonesian/English/system UI language, persistent light/dark/system appearance, native Android interactions and tablet support are established product constraints.
